**[本文を読む — BOOK.md](BOOK.md)**　／　**[設計成果物を読む](docs/README.md)**

本文は完成版PDFと同じ全16章・付録6点、図23点・表102点を収録しています。図表番号と順序を対応させ、図は拡大できるSVG、表は編集可能なMarkdown表として配置しています。

要件定義書・外部設計書・内部設計書などは、同じ案件を開発成果物の形式に具体化した文書です。図書本文の判断経緯と、各文書の仕様・受入条件を行き来できます。
