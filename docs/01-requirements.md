## 1. 目的・背景と評価の基準

購入後の安心を事業上の強みにするため、受付の検索・記録負荷と引継ぎ漏れを減らす。AIの利用回数を成功指標にせず、顧客の用件が責任ある担当へ渡り、最後まで完了することを目的とする。

| ID | 要求・背景 | 数値・判断基準 | 責任者 |
| --- | --- | --- | --- |
| S-01 | 購入後の安心で選ばれる | 誤確約を防ぎ、部門を越えて対応を継続できる | 松田 |
| B-01 | 再問い合わせと有人負荷を減らす | 基準月：新規10,000件、有人初回10,000回、追加2,000回、12分／回、2,400時間 | 高橋 |
| B-02 | 保証・費用・日程の誤確約と情報漏えいを防ぐ | 安全・対象認可・未承認実行の重大条件を全件合格 | 森・岡本 |
| B-03 | 障害や担当交代後も仕事を継続する | 未完了案件に担当・次行動・期限があり、結果不明を照合できる | 高橋・岡本 |

9月の評価例は自己解決1,600件、有人8,400初回＋1,200追加、9.5分／回、1,520時間である。これは物語内の評価結果であり、要件合意時点で達成済みだった数値ではない。削減880時間をそのまま現金支出削減へ換算しない。

## 4. 業務ルール・制約

| ルールID | 合意事項 | 違反時の扱い |
| --- | --- | --- |
| BR-01 | 安全に関する申告を通常の保証・受付質問より優先 | 承認済み安全案内と品質保証への引継ぎ。再現のための再運転は求めない |
| BR-02 | 直販履歴と販売店購入を区別 | 注文が見つからないことを未購入・保証無効と判定しない |
| BR-03 | メーカー保証、販売店保証、延長契約の提供者を特定 | 契約窓口と必要証憑を確認し、他社負担を確約しない |
| BR-04 | 通常修理は修理受付経路、安全・規約例外等は例外経路 | すべてを例外チケットへ送らない。進捗照会で該当なしでも自動新規作成しない |
| BR-05 | 受付成立、訪問予約、作業完了、案件完了を区別 | 受付番号があっても訪問確定とは表示しない |
| BR-06 | 完成品の在庫・生産と補修部品の在庫を分離 | 完成品CSVや生産RPAを部品引当に使わない |
| BR-07 | 金額・対象・作業内容の変更では新しい版を確認 | 古い承認・顧客同意による実行を拒否 |
| BR-08 | 未完了案件には次の責任者と期限が必要 | 担当が決まらなければSVの割当作業を残す |

## 5. 機能・非機能要件と受入条件

以下のR-01～R-16を要件の基準とする。安全・認可・更新の一意性・追跡性はMust、回答の短さや根拠順序は重大条件を満たしたうえで改善するShouldとする。

要件の理由は[第3章](../BOOK.md#chapter-3)、実現方法は第4～10章、検証は[第11章](../BOOK.md#chapter-11)で追える。ここでは、各要件を合意・受入に使う形で一覧化する。

### R-01～R-04　根拠・対象・判断・引継ぎ

**システム要件と受入条件**

| 要件 | 設計上の要求 | 受入条件・証拠 |
| --- | --- | --- |
| R-01<br/>根拠のある一次回答 | 対象機・有効な規約・公開範囲に一致する根拠を使う。根拠なしは要確認とする。 | 用件と型番を変えたケースで他機種の操作を返さず、参照文書と版を追える。T05・T06・T10。 |
| R-02<br/>本人確認と個別認可 | 個別注文・案件は、実行主体と対象への権限を接続先で検証する。 | 他人の注文番号を入力しても内容を返さず、モデルによる利用者IDの差替えが効かない。T21。 |
| R-03<br/>保証判定の分離 | 期間、適用見込み、要確認、最終負担を分ける。 | 期間内・原因未確定の案件を無償確約しない。証憑不足を無効としない。T03・T04・T20。 |
| R-04<br/>引継ぎの成立 | 確認済み／未確認、試した操作、希望、担当、期限を渡す。 | 受け手が引受けるまでは送り手が追跡でき、未引受けを抽出できる。T09・T24。 |

## 8. 変更管理と文書の完了条件

変更要求は目的、依頼者、対象要件、影響データ・権限・試験、費用・工程、代替案を記録する。松田が価値と範囲、現場が業務成立、森が保証・安全、岡本が技術・統制を確認する。CR-03の配送先自動変更とCR-07の見積自動送信は初期対象へ無条件追加しない。

本書の完了条件は、R-01～R-16に設計・試験の参照先があること、対象外の受付先が決まっていること、未確定事項に所有者と期限があることである。仕様書が存在するだけで本番受入とはしない。
